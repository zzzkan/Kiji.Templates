Every notebook starts with an empty page. This one starts with a small promise:
write something down before the detail slips away.

It might be a question, a sketch of an idea, or a sentence from the day. It does
not have to be finished to be worth keeping.

## Leave room to return

Short notes are easy to revisit. A few lines now can become a longer piece later.

> Start with the part you want to remember.
