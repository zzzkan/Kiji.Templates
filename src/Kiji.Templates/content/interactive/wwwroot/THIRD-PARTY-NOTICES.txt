ASP.NET Core Blazor WebAssembly template
---------------------------------------
Source: https://github.com/dotnet/aspnetcore/tree/v10.0.13/src/ProjectTemplates/Web.ProjectTemplates/content/ComponentsWebAssembly-CSharp
Reference: dotnet new blazorwasm from .NET SDK 10.0.402 (ASP.NET Core 10.0.13).

The Layout components and scoped styles, Pages markup, wwwroot/css/app.css,
and wwwroot/sample-data/weather.json are adapted from this template.
Kiji supplies static rendering, page routing and asset URLs; collocated
JavaScript supplies the client interactions. Runtime-specific Blazor startup,
loading and error UI are omitted. The favicon uses the Unicode rocket emoji,
rendered with the visitor's system emoji font.
